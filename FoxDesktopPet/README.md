# 🦊 FoxDesktopPet — 可愛的小狐狸

一隻使用 Python 製作的 Windows 桌面像素風小狐狸！

小狐狸會在桌面上自由走動、睡覺、跳舞，也可以透過滑鼠與牠互動，讓電腦桌面變得更有趣。

## ✨ 功能介紹

- 🐾 **自由走動**：小狐狸會在桌面上散步。
- 🖱️ **滑鼠互動**：可以摸摸狐狸、拖曳牠，也能讓牠跟隨滑鼠。
- 💤 **睡覺系統**：可以讓小狐狸休息睡覺。
- 🍎 **餵食系統**：餵狐狸吃東西，增加好感度。
- 💗 **好感度系統**：和狐狸互動可以提高好感度。
- 🎀 **換裝系統**：可以替狐狸更換造型。
- 🎵 **音效功能**：互動時會有簡單的提示音效。
- 📚 **讀書提醒**：可以設定讀書與休息時間。
- 💬 **指令系統**：輸入指令控制小狐狸。

## 💻 執行環境

- Windows 10 / Windows 11
- Python 3.10 以上版本
- 不需要額外安裝第三方 Python 套件

## 📥 安裝與使用方法

### 1. 下載專案

點選 GitHub 頁面右上角的綠色 `Code` 按鈕，選擇 `Download ZIP`，下載後解壓縮。

### 2. 安裝 Python

如果電腦尚未安裝 Python，請先前往：

https://www.python.org/downloads/

安裝時建議勾選 `Add Python to PATH`。

### 3. 啟動小狐狸

如果資料夾中有 `啟動橘子狐狐.bat`，直接點兩下執行。

也可以在程式資料夾開啟終端機，輸入：

```bash
python fox_pet.py
```

執行後，小狐狸就會出現在桌面上！

## 🎮 操作方式

| 操作 | 功能 |
|---|---|
| 左鍵點擊狐狸 | 摸摸狐狸，增加好感度 |
| 左鍵拖曳狐狸 | 移動狐狸位置 |
| 右鍵點擊狐狸 | 開啟功能選單 |
| 左鍵點擊兩下 | 開啟控制面板 |

## 💬 指令介紹

在小狐狸的控制面板輸入以下指令：

| 指令 | 功能 |
|---|---|
| `/feed` | 餵食狐狸 |
| `/sleep` | 讓狐狸睡覺 |
| `/dance` | 讓狐狸跳舞 |
| `/study` | 開始讀書計時 |
| `/quit` | 關閉程式 |
| `/help` | 查看支援的指令 |

其他功能可以透過狐狸的右鍵選單操作。

## 📚 讀書提醒功能

小狐狸也可以當你的讀書小助手！

預設讀書時間為 25 分鐘，休息時間為 5 分鐘。

讀書時間結束後，小狐狸會提醒你休息。
