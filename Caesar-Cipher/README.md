#  Caesar Cipher 凱薩密碼

## 一、專案介紹與原理

首先先來講講為什麼我會想做這個專案好了 ^_____^

凱薩密碼是古典密碼學中相對簡單的一種加密方式，主要是透過英文字母固定的位移格數來進行加密。

例如：我在解 CTF 題目的時候，有時會遇到像 `Kono{...}` 這樣的 Flag 格式，而題目中的某段文字可能經過凱薩密碼加密。

如果知道它使用的是凱薩密碼，我們就可以嘗試不同的位移格數，找出原本的文字。

例如：

- 原始文字：`ABC`
- 位移格數：`3`
- 加密結果：`DEF`

解密時只要將字母往回移動 3 格，就可以還原成 `ABC`。

因為之前有接觸過這類型的 CTF 題目，所以這次我想試著自己用 Python 寫出一個可以加密和解密的凱薩密碼工具。

## 二、程式功能

可以自行選擇加密或解密。

可以設定想要位移的格數。

支援英文大小寫。

當字母超過 Z 時，會重新從 A 開始。

遇到數字或特殊符號時，會保留原本的內容。

## 三、程式運作原理

這次主要使用 Python 的 for 迴圈、if 判斷式，以及 ord()、chr() 來完成凱薩密碼的加解密。

程式會先透過 input() 讓使用者輸入文字、位移格數，以及要加密還是解密。

接著使用 for 迴圈，一個字母一個字母進行處理。

其中 ord() 可以將字母轉換成數字，讓程式利用數字進行位移運算。

因為英文只有 26 個字母，所以使用 % 26 取餘數，讓字母超過 Z 時可以重新從 A 開始。

最後再使用 chr() 將計算後的數字轉回字母，組合成加密或解密後的結果。
