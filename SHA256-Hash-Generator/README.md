
# SHA-256 Hash Generator 🔐

## 專案介紹
使用 Python 製作的 SHA-256 雜湊產生器。
使用者輸入文字後，程式會產生對應的 SHA-256 雜湊值。

## 使用技術
- Python
- hashlib

## 功能
- 輸入任意文字
- 將文字轉換成 UTF-8 位元組
- 計算 SHA-256 雜湊值
- 顯示計算結果

## 使用方法
1. 安裝 Python 3
2. 執行 `python main.py`
3. 輸入文字
4. 查看 SHA-256 結果

## SHA-256 運作原理

### 1. 什麼是 SHA-256？

SHA-256 是一種雜湊演算法，可以將輸入的資料轉換成固定長度的 256 位元雜湊值，通常會以 64 個十六進位字元呈現。

SHA-256 與一般加密不同，雜湊是單向運算，無法直接將結果解密回原始資料。

### 2. 程式運作流程

1. 使用 `input()` 讓使用者輸入文字。
2. 使用 `.encode("utf-8")` 將文字轉換成位元組。
3. 使用 `hashlib.sha256()` 計算 SHA-256 雜湊值。
4. 使用 `.hexdigest()` 將結果轉換成十六進位字串。
5. 使用 `print()` 顯示原始文字與雜湊結果。

### 3. SHA-256 的特色

- **固定長度：** 不論輸入資料大小，輸出都是 256 位元。
- **單向性：** 無法直接從雜湊值還原原始資料。
- **雪崩效應：** 即使輸入只改變一個字元，雜湊結果也可能產生很大的差異。
- **資料完整性驗證：** 可以透過比較雜湊值，檢查資料是否發生變動。
