
# SHA-256 Hash Generator 🔐

## 專案介紹
使用 Python 製作的 SHA-256 雜湊產生器。
使用者輸入文字後，程式會產生對應的 SHA-256 雜湊值。

## 使用技術
- Python
- hashlib

## 功能
- 輸入任意文字
- 將文字轉換成 UTF-8 位元組
- 計算 SHA-256 雜湊值
- 顯示計算結果

## 使用方法
1. 安裝 Python 3
2. 執行 `python main.py`
3. 輸入文字
4. 查看 SHA-256 結果

## 學習重點
- 了解 SHA-256 雜湊演算法
- 學習使用 hashlib 函式庫
- 認識字串與位元組的差別
- 了解雜湊與加密的不同
