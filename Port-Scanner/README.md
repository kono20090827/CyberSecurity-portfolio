# Port Scanner

## 專案介紹

使用 Python 製作的簡易 Port Scanner（連接埠掃描工具）。

本工具透過 Socket 技術，檢查本機電腦是否有開放的網路服務，協助了解電腦網路安全狀態。

## 功能

- 掃描常見 Port
- 檢測 TCP 連線狀態
- 顯示開放的 Port
- 使用 Timeout 機制提升掃描速度
- 計算掃描時間

## 使用技術

- Python
- Socket
- TCP 連線

## 執行方式

輸入：

py main.py

## 執行結果範例

開始掃描：127.0.0.1

開放 Port: 445

掃描完成

## 學習心得

這是我第一次製作 Port Scanner，我利用 ChatGPT 輔助學習 Python Socket 的使用方式，並理解 Port 掃描的基本原理。

第一次執行測試時，由於程式採用逐一測試 Port 的方式，導致掃描速度非常慢，等待約五分鐘仍未完成，因此我重新檢查程式架構並重新撰寫。

第二次我加入 Timeout 機制來改善執行效率，掃描速度明顯提升，也讓我體會到程式除了功能正確之外，效能優化同樣重要。雖然目前的版本仍有進步空間，但我未來希望嘗試多執行緒（Multithreading）等技術，持續提升掃描效率與工具的完整性。
